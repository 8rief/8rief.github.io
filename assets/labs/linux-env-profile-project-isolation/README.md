# Linux environment/profile/project isolation lab

This lab supports the public teaching post about environment variables, Bash startup files, and project-local environment isolation.

Run:

```bash
./run_lab.sh
```

Expected artifacts:

- `reports/env_profile_probe.json`: machine-readable probe results.
- `reports/transcript.md`: commands, return codes, first output lines, and interpretation.
- `reports/environment_summary.md`: checklist for a project environment note.
- `reports/run_lab_output.txt`: terminal transcript.
