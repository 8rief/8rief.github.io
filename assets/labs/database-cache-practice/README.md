# Database and Cache Practice Lab

A Python standard-library lab for practical database and cache development:

- SQLite schema and migrations via `PRAGMA user_version`
- parameterized CRUD
- index and `EXPLAIN QUERY PLAN`
- transaction-backed order placement
- cache-aside report caching
- TTL expiry and explicit invalidation
- JSON, Markdown, and SVG reports

Run:

```bash
bash run_lab.sh
```
