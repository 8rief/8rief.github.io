# Software Project Structure Foundations Lab

A stdlib-only Python lab for software-engineering project structure. It demonstrates requirement slicing, directory layout, module boundaries, configuration validation, JSON storage with atomic writes, CLI contracts, tests, documentation, demo transcript, and a release checklist.

Run:

```bash
bash run_lab.sh
```

Generated artifacts:

- `reports/transcript.txt`: full transcript.
- `reports/demo_output.txt`: CLI demo output.
- `reports/project_tree.txt`: generated demo project tree.
- `reports/release_checklist.md`: release gate summary.
- `.lab_tmp/`: generated demo workspace, recreated by `run_lab.sh`.
