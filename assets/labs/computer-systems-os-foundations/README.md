# Computer systems and OS foundations lab

This local lab keeps all demonstrations in Linux user space. It builds one C program and records observable evidence for data representation, memory layout, process creation, file descriptors, virtual memory, thread synchronization, signals/IPC, and cache locality.

Run:

```bash
bash run_lab.sh
```

Main outputs:

- `reports/metrics.json`
- `reports/report.md`
- `reports/transcript.txt`
- `reports/*.svg`

The lab intentionally avoids kernel modification and offensive security exercises.
