# Algorithm Practical Foundations Lab

A small C++20 lab for practical algorithm foundations. It uses deterministic examples and a tiny assertion harness, then writes a Markdown report and a JSON summary.

Run:

```bash
bash run_lab.sh
```

Generated artifacts:

- `reports/transcript.txt`: full command transcript.
- `reports/test_output.txt`: executable output.
- `reports/algorithm_report.md`: human-readable result report.
- `reports/results.json`: machine-readable summary.
- `.lab_tmp/algorithm_practical_foundations`: compiled binary, recreated by `run_lab.sh`.
