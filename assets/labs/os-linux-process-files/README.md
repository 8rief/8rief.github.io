# OS/Linux process and file fundamentals lab

This local lab supports the OS/Linux foundations teaching package. It creates a controlled workspace, records filesystem, descriptor, process, environment, permission, signal, and text-pipeline observations, then writes a Markdown report and JSON evidence file.

Run:

```bash
./run_lab.sh
```

Artifacts:

- `reports/transcript.txt`: command transcript.
- `reports/system_observer_report.md`: human-readable evidence report.
- `reports/observations.json`: machine-readable observations.
- `workspace/`: lab-owned sample files and generated outputs.

The lab does not scan the network, modify system files, or require elevated privileges.
