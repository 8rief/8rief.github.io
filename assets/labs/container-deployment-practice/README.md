# Container Deployment Practice Lab

A local Docker lab for zero-beginner containerization and deployment practice:

- Python standard-library HTTP app
- Dockerfile, image build, container run
- loopback port publishing
- environment variable configuration
- bind-mounted persistent state
- Docker health check, logs, inspect, and Compose config
- JSON, Markdown, SVG, and transcript reports

Run:

```bash
bash run_lab.sh
```

The script uses only the lab-owned image tag `container-deployment-practice:local` and container name `container-deployment-practice-web`.
