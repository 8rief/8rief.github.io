# Deep Learning AI Engineering Lab

A CPU-only NumPy lab for deep-learning/AI engineering foundations:

- synthetic supervised dataset
- majority and linear baselines
- one-hidden-layer NumPy MLP
- softmax cross entropy
- manual backpropagation and gradient check
- train/validation/test metrics
- checkpoint, model card, report, SVG curve, transcript

Run:

```bash
bash run_lab.sh
```
