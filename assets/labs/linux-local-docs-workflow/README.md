# Linux local documentation workflow lab

This lab supports the public teaching post about reading local help, manual pages, module docs, and version output before copying commands into a project.

Run:

```bash
./run_lab.sh
```

Expected artifacts:

- `reports/doc_probe.json`: machine-readable command checks.
- `reports/transcript.md`: command, return code, first output lines, and interpretation.
- `reports/learning_check.md`: compact checklist for what each documentation source proves.
