# Linux PATH and package resolution lab

This lab supports the public teaching post about how Linux resolves command names through shell lookup, PATH order, executable bits, and Debian/Ubuntu package metadata.

Run:

```bash
./run_lab.sh
```

Expected artifacts:

- `reports/package_path_probe.json`: machine-readable probe results.
- `reports/transcript.md`: commands, return codes, first output lines, and interpretation.
- `reports/resolution_summary.md`: the checklist for debugging command lookup.
- `reports/run_lab_output.txt`: terminal transcript.
