# SQL Practical Development Lab

This lab uses Python's standard `sqlite3` module to demonstrate practical SQL development without requiring a separate database server.

Run everything:

```bash
bash run_lab.sh
```

What it creates:

- `.lab_tmp/tickets.db`: a local SQLite database file.
- `reports/transcript.txt`: full command transcript.
- `reports/demo_output.txt`: capstone CLI output.
- `reports/test_output.txt`: unittest output.
- `reports/open_tickets.csv`: CSV export.
- `reports/report.json`: JSON export.
- `reports/sql_lab_report.md`: short human-readable report.
